# Brava Kayak HUB

## Descripción

Brava Kayak HUB es una empresa especializada en el alquiler de kayaks y paddle surf ubicada en Playa de Fenals (Lloret de Mar, Costa Brava).

La página web tiene como objetivo transmitir una imagen moderna, profesional y aventurera, destacando la calidad del material, la experiencia del equipo y la belleza del entorno.

## Objetivos

- Mostrar los servicios disponibles.
- Mostrar tarifas.
- Generar confianza.
- Facilitar el contacto mediante WhatsApp.
- Posicionarse en Google para búsquedas relacionadas con kayak y paddle surf en Lloret de Mar.

## Tecnologías

- HTML5
- Tailwind CSS
- JavaScript
- Responsive
- SEO optimizado

## Inspiración

La web debe seguir el estilo visual de la imagen de referencia ubicada en la carpeta **assets/**.
